CARA MEMASANG FOTO
------------------
Masukkan foto ke folder assets dan beri nama tepat:

photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg
photo5.jpg
photo6.jpg

Kalau foto belum ada, website tetap bisa berjalan dan akan menampilkan gambar pengganti.

CARA MEMASANG MUSIK
-------------------
Kalau ingin memakai musik latar:

1. Masukkan file MP3 ke folder assets.
2. Beri nama music.mp3.
3. Tombol Musik Menyala / Musik Mati di website akan otomatis bekerja.

Kalau tidak ingin memakai musik, tombol musik bisa dihapus dari index.html.

CARA MENCOBA
------------
Buka index.html menggunakan Chrome.

Lebih nyaman kalau dibuka melalui VS Code + Live Server agar mudah diedit.

UPLOAD KE VERCEL
----------------
1. Ekstrak file ZIP.
2. Buka Vercel.
3. Buat proyek baru atau unggah folder website.
4. Lakukan deploy.
5. Setelah mendapatkan tautan, tautan tersebut bisa dibuat menjadi QR Code.
